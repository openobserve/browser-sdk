# RUM Browser Monitoring - slim package

## Overview

This package is equivalent to the [RUM package][1], but without support for Session Replay
recording and the `compressIntakeRequests` initialization parameter. Use it when you do not need
session replay and want a smaller bundle.

## Setup

See the [`@openobserve/browser-rum`][1] documentation, or the
[OpenObserve RUM documentation][2].
