# `browser-core`

> **Internal package.** Shared building blocks for the OpenObserve browser SDKs. It is not
> intended for direct use, and its APIs may change without notice.

OpenObserve browser core utilities.

To collect RUM data, use [`@openobserve/browser-rum`][1]. To collect logs, use
[`@openobserve/browser-logs`][2]. See the [OpenObserve RUM documentation][3] for setup
instructions.
